# Gangotri Glacier Retreat Detection with Attention U-Net

Deep learning pipeline for mapping and forecasting the retreat of the Gangotri Glacier
(Uttarakhand, India) from multi-year Sentinel-2 satellite imagery. An Attention U-Net
is trained to segment glacier extent from spectral index composites, evaluated against
a traditional NDSI-thresholding baseline, and used to project glacier area through 2030.

## Problem

Glacier boundaries are conventionally mapped by hand or via a single-band NDSI
(Normalized Difference Snow Index) threshold. Simple thresholding is fast but brittle —
it misconstrues shadow, debris cover, and seasonal snow as glacier ice, so year-over-year
area estimates fluctuate in ways that don't reflect real retreat. This project trains a
segmentation model on multi-spectral input (NDSI + NDWI + NDVI) to produce more stable,
more accurate glacier masks across a 7-year time series, then uses that time series to
quantify retreat and forecast future area loss.

## Approach

1. **Imagery** — Sentinel-2 L2A composites (2017–2023) sourced via Google Earth Engine
   for the Gangotri Glacier region, post-monsoon season (July–October) to minimize
   transient seasonal snow.
2. **Spectral indices** — each yearly composite is reduced to 3 channels: NDSI (snow/ice),
   NDWI (water), NDVI (vegetation), each normalized to [0, 1].
3. **Ground truth** — glacier outlines from the Randolph Glacier Inventory (RGI v7),
   rasterized to a binary mask aligned with the Sentinel-2 grid.
4. **Segmentation model** — an Attention U-Net (4-level encoder/decoder, attention gates
   on every skip connection) trained on 256×256 patches with a combined Dice + BCE loss.
5. **Baseline** — a classic NDSI-thresholding segmentation, computed on the same imagery,
   used as the point of comparison for both accuracy and year-over-year stability.
6. **Temporal analysis** — the trained model is run on all 7 years of full-resolution
   imagery (patch-based inference, stitched with overlap-averaging) to produce a glacier
   area time series, from which retreat rate and a 2024–2030 forecast are derived via
   linear and polynomial regression.

## Results

| Metric | Value |
|---|---|
| IoU (Jaccard) | 0.8445 |
| Dice score | 0.9153 |
| Precision | 0.9064 |
| Recall | 0.9248 |
| F1 score | 0.9155 |
| Year-over-year stability vs. NDSI baseline | 38× improvement |
| Glacier area loss (2017–2023) | 14.09 km² |
| Forecast horizon | through 2030 (linear + polynomial regression) |

## Tech stack

- **Modeling**: PyTorch (Attention U-Net)
- **Imagery source**: Sentinel-2 L2A via Google Earth Engine
- **Geospatial processing**: rasterio, geopandas
- **Analysis / forecasting**: scikit-learn (linear & polynomial regression), NumPy
- **Visualization**: Matplotlib

## Project structure

```
data/
  raw/         Sentinel-2 GeoTIFF composites per year (not included — see below)
  processed/   Preprocessed .npy arrays and training splits (not included — see below)
  rgi/         RGI glacier outline mask (GeoTIFF)
src/
  preprocess.py      Builds training patches from raw imagery + RGI mask
  model.py            Attention U-Net architecture
  train.py            Training loop, loss, metrics
  ndsi_baseline.py     NDSI-thresholding baseline segmentation
  full_analyze.py      Runs the trained model across all years, computes area/forecast, generates figures
outputs/
  plots/       Generated figures
  results/     Training log
```

## Running it

Raw and processed imagery/data files are not checked into this repository (multi-GB
satellite composites and training arrays) — you'll need your own Sentinel-2 exports
and RGI outlines to reproduce the pipeline end to end.

```bash
pip install torch numpy rasterio geopandas tqdm matplotlib scikit-learn

# 1. Place yearly Sentinel-2 GeoTIFFs in data/raw/ and an RGI shapefile in data/rgi/,
#    then build training patches:
python src/preprocess.py

# 2. Train the Attention U-Net (GPU recommended):
python src/train.py

# 3. Quick baseline-only sanity check (no trained model needed):
python src/ndsi_baseline.py

# 4. Full temporal analysis — runs the trained model across all years,
#    computes glacier area, forecasts through 2030, generates all figures:
python src/full_analyze.py
```
